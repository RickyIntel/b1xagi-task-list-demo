# B1Xagi task-list demo

Originally generated by B1Xagi Zero during the local acceptance run. Codex repaired
storage-unavailable handling and added accessible input/checkbox labels afterward.

Serve this directory on localhost with `python -m http.server 8879 --bind 127.0.0.1`.
Chrome retains tasks in localStorage. B1Xagi's opaque embedded preview operates in
session-only mode and explicitly warns that reload resets tasks. No server,
external dependencies, account connection or network requests are required.
